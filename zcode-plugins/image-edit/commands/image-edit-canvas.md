打开本地「改图」画布。用户要在图上亲手涂抹要改的区域，不要用模型去猜遮罩。

任务说明：$ARGUMENTS

必须遵守：

1. 调用 MCP 工具 `image_edit_open`（它会先 ensure 本地服务再打开浏览器）。
2. 把返回的本地地址发给用户，例如 http://127.0.0.1:8000/ 。
3. 不要替用户指定矩形或自动生成遮罩；涂抹只发生在画布页上。
4. 不向用户索要 Key 经对话转发；服务端已配置 Key 时页面可以留空，Base URL 必须对应同一凭据。主 AI/CLI 流程不因安装该画布而被替代。
