# 手工改图画布（可选入口）

仅用于用户明确选择的手涂/矩形画布任务。一般自然语言图生图或姿态迁移仍走 `style-distill` 分析 + `image-edit` CLI，不默认要求用户去网页操作。

## 标准顺序

1. 调用 MCP `image_edit_open`，只有 ensure 成功才打开浏览器。
2. 返回实际本机 URL，用户绘制区域后可以在网页显式提交。若只是导出遮罩，回到主 CLI 的 `--mask-file` 流程。
3. 不向用户索要 API Key 通过对话传递。服务端有默认凭据时页面 Key 留空；手动填写的 Key 会保存在本人浏览器 localStorage。
4. 只要状态用 `image_edit_status`；明确停止用 `image_edit_stop`。身份未确认时禁止根据旧 PID 猜测并终止进程。
5. HTTP 200 只表示请求/下载完成，仍需对照用户要求验收角色、动作、构图、文字与修改范围。本网页没有主 CLI 的保护区量化、Job/cache 或自动语义验收。

## 能力

- 画笔、橡皮、反选、全填、矩形选中/拖动/Delete、复制遮罩。
- 整图和局部改图、多张参考、图生图/文生图参数面板。
- 结果缩放平移、按住对比、并排/滑动对比、缩略图。
- 视频为实验性入口，不能宣称未经测试的模型/端点可用。

## 提交与安全

- 局部通道发涂红主图与参考图，正文声明「红色是标记」，不会同时发干净原图；这是特定上游实测方法，不是普遍像素保护保证。
- 不自动重试生成 POST。超时/断连/5xx 可能已受理，应先查询任务/账单；下载失败不重新生成。
- 凭据与 Base URL 成对使用，不把服务端旧 Key 自动发给用户临时切换的新端点。
- 只监听 127.0.0.1，检查 Host/Origin；不可暴露公网。
- 图片代理和结果 URL 拒绝私有/环回/链路本地地址及重定向，不把中转 Bearer 发送给 CDN。

## 环境

Python 3.10+，在实际解释器安装插件 `requirements.txt`（Pillow 和 MCP 1.x）。MCP 的 Python 路径、端口可在插件 userConfig 中配置。
